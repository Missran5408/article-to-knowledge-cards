# 文献翻译

把英文（或中英混排）的论文、综述、技术报告、标准与专利逐**自然段**译成中文，每段配一张四字段知识卡片，并保证术语在本学科内正确。

**优先级**：用户显式要求 > 本文件的输出模板 > 默认规则。用户说「只要译文」「不要摘录」「输出到某个文件」时照办，并同步省略与之冲突的默认项；但「译文规则」与术语表始终生效。

## 工作流

### 第 1 步：识别输入

| 输入 | 动作 |
|---|---|
| 粘贴的文本（消息正文） | 直接进入第 2 步 |
| 本地文本文件（`.txt`、`.md`、`.csv` 等） | 读到内容后按「粘贴的文本」处理 |
| 本地 PDF 路径 | 按「PDF 文本提取」取文本，成功后再进入第 2 步 |
| 本地 `.docx`/`.doc` 等 | 先转成文本（`pandoc`、`libreoffice --convert-to txt` 等），转不了就请用户粘贴正文 |
| PDF 无文本层，或只有图片 | 按「扫描版或图片型 PDF」处理，不进入翻译流程 |
| 只有截图 | 逐图识读后翻译，并在「说明」行声明「内容来自图像识别，可能有误」 |

判定顺序是**先看有没有正文，再看正文能不能提取**。取不到正文（正文为空、整页空白、全是乱码）时直接走扫描版流程并给出三条出路，不要反问「正文是不是空的」；只有在用户只给了文件名或半句话、正文根本没给出来时，才先追问正文来源。任何情况下都不得凭猜测补写原文。

### 第 2 步：先判定学科，再动笔

动笔前确定并写出这几行：学科与子领域、文体、术语基准，以及需要标注的存疑项。它们就是「输出模板」开头的那几行，**不要另起一段重复声明**。

- **学科与子领域**：如 分子生物学 / 单细胞转录组；流体力学 / 鱼类推进；强化学习 / 策略优化
- **文体**：研究论文、综述、教材、技术标准、专利、科普
- **术语基准**：全国科学技术名词审定委员会公布名词、GB/T 术语、学科经典教材译名、IEEE/ACM/ACS 等惯例

学科判定决定术语选择。**先定领域，再动笔**；同一篇文献的术语必须全篇一致。两项标注可能同时成立（如非英语外语且领域未明）时用分号并列写出，不要只留一条。

### 第 3 步：先建术语表，后翻译

通读全文，抽出关键术语、确定标准译名，在输出开头给出术语表。

- **选词标准**：满足任一条即为关键术语——出现在题名、摘要或小标题中；进入公式或图表；全篇出现 3 次以上；属于该学科的核心概念。
- **条数**：5–30 条（常见 5–20）。术语密集的文献取上限，宁可多列以保证全篇一致。
- **存疑术语**：写在该行的「依据」列，形如 `译名存疑（另译 椎节）`，不要生造一个看起来专业的词顶上去。
- **正文附注（唯一规则）**：每个术语只在**全篇首次出现**处附一次英文原词，写成「中文译名（English term）」，**任何术语都不得重复附注**；**每段附注合计不超过 3 处**（硬性上限）。小标题里的出现也算首次出现。
- **附注计数口径**：只数「中文译名（English term）」这类术语附注；原文自带的括号（数值、单位说明、`mean ± s.d.`、`n = 12` 等）不计入上限。
- **候选超额时的优先级**：段内首次出现的候选术语多于 3 个时，按序取前 3 处——①出现在公式或图表中的；②命中「高频易错术语」表的；③属于该学科核心概念的；④按正文出现顺序。其余术语只写中文，读者查术语表即可。
- **不附注**：中文译名与英文原词相同、或本身就是符号的术语（`TCF7`、`CD19`、`Transformer`、`softmax`、`ImageNet`）不写「中文（English）」，避免 `TCF7（TCF7）`。无量纲数与变量的中文名（如 雷诺数、斯特劳哈尔数）仍按上面规则正常附注一次，变量符号本身原样保留、不附注。
- 下面的「高频易错术语」表只用于选词，不替代本术语表，也不改变附注规则。

| 原文术语 | 推荐译名 | 依据 |
|---|---|---|
| Strouhal number | 斯特劳哈尔数 | 流体力学无量纲数 |
| relapsed or refractory | 复发或难治性 | 肿瘤学通行译名 |
| vertebral joint | 脊椎关节 | 译名存疑（另译 椎节） |

### 第 4 步：逐段输出卡片

按「分段规则」切段，逐段输出「原文摘录 + 译文 + 知识卡片」。格式见「输出模板」。

### 第 5 步：交付前自检

逐条过「自检清单」再输出。发现不合规就改，不要把问题留给用户。

## PDF 文本提取

优先用已有工具，其次用 pypdf，都不可用才回退人工。

```powershell
# 1) poppler 的 pdftotext（最快、版面保留最好）
pdftotext -layout "paper.pdf" -

# 2) 通用回退：pypdf
python -m pip install --quiet pypdf
python -c "import sys,pypdf;print('\n\n[[PAGE_BREAK]]\n\n'.join((p.extract_text() or '') for p in pypdf.PdfReader(sys.argv[1]).pages))" "paper.pdf"
```

```bash
# macOS / Linux 用同样两条命令
pdftotext -layout paper.pdf -
python -c "import sys,pypdf; print('\n\n[[PAGE_BREAK]]\n\n'.join((p.extract_text() or '') for p in pypdf.PdfReader(sys.argv[1]).pages))" paper.pdf
```

路径含空格时用引号包住；Windows 路径不要以反斜杠结尾。若报路径或转义错误，先 `cd` 到 PDF 所在目录再用文件名，或把反斜杠换成正斜杠——在 `python -c` 的代码里直接写死 Windows 路径时，`\U`、`\t`、`\r` 会被当成转义序列。

### 提取后的清理

1. **合并段内硬换行**：同一自然段内的换行改成空格，保留空行作为段界。
2. **保留分页标记**：pypdf 命令会把各页用 `[[PAGE_BREAK]]` 连起来。它用于统计页数（无文本层判据需要它），并避免把跨页处的短行误判为段末；**段界不得落在分页标记处**，除非标记两侧同时满足信号 2 与信号 3。输出译文时删掉标记。
3. **剔除非正文**：页码、期刊页眉、DOI 水印、行号、作者与单位行、版权行、参考文献条目都不要当成正文段落。
4. **英文断词**：行尾连字符（`infor- mation`）还原成 `information`，但 `well-known` 这类真连字符保留。
5. **还原失真的符号**：按「符号与格式约定」处理。
6. **同形字符靠上下文判断**：`0.41 +/- 0.03`（正负号）、`0.25-0.35`（区间）、`multi-joint`（真连字符）在字符层同形，按语境区分。

### 段界恢复（pypdf 常把空行压掉）

`pdftotext -layout` 一般保留空行；pypdf 输出往往**一整页没有空行**，此时按下列信号由强到弱恢复段界，并在「说明」行写出依据：

1. 空行（存在就直接用）。
2. **段末行明显短于主体行宽**（未顶到右边界）——断行与段落收尾最可靠的版面差异。纯文本没有版面数据时，用**全篇最长行的字符数**作为主体行宽代理；段末行短于主体行宽的 **85%** 即算「明显短」。
3. **段首标记**：`In this study`、`Here we`、`We`、`The experiments`、`These findings`、`However`、`In contrast`、`Finally` 等。
4. **语义与体貌转换**：背景→方法、方法→结果、陈述现在时→实验过去时。
5. 章节编号或小标题行。

切完把恢复出的段数报给用户。**低置信度**指：段末行长度落在主体行宽的 85%–100% 之间（含 85%），或信号 2 与信号 3 给出矛盾的切点。信号 2 与信号 3 矛盾时**以信号 2 切分**，并在「说明」行写明「段界为版面推断，可能与原文不符」。

### 无文本层判据

清理后**取不到正文**即判为无文本层，转入扫描版流程。具体表现：总字符数少于 200；平均每页少于 50 字符；大量 `\ufffd` 与乱码；整页空白（可能是纯图片页）。判据看的是能不能取到正文，与有没有乱码无关。

## 扫描版或图片型 PDF

明确告知用户「该 PDF 没有可提取的文本层（扫描件或图片型），无法可靠提取正文」，并给出三条出路：

1. 用 OCR 工具（OCRmyPDF、Adobe Acrobat、WPS 或福昕的 OCR）生成文本层后再来；
2. 直接把正文粘贴进对话；
3. 提供页面截图，逐页读图翻译（此时在「说明」行声明「内容来自图像识别，可能有误」）。

禁止用「看起来像」的内容填补缺失正文。若该页只是封面或插图，提醒用户直接给包含正文的页面。

## 符号与格式约定

粘贴文本与 PDF 提取文本都可能出现排版失真。译文按下列约定统一还原，并在「说明」行注明「符号已按标准还原」：

| 源文本形态 | 译文写法 | 说明 |
|---|---|---|
| `rho`、`alpha` | `ρ`、`α` | 希腊字母还原 |
| `+/-` | `±` | 正负号 |
| `q.k`、`T D` | `q·k`、`T·D` | 算符丢失时补回 `·` |
| `kg/m3`、`U^2` | `kg·m⁻³`、`U²` | 单位与幂用上标 Unicode |
| `Cd`、`dk` | `C_d`、`d_k` | 变量下标用线性写法，Markdown 中更稳 |
| `1.2 x 10^5` | `1.2 × 10⁵` | 科学计数法用 `×` 与上标 |
| `0.25-0.35` | `0.25–0.35` | 数字区间用连接号 |
| `multi- joint` | `multi-joint` | 行尾断词还原，真连字符保留 |

- 只改写法，**数值一律不变**。
- 同一符号在原文中表示不同量（如 `A` 既是尾摆幅又是面积）时，写在**该符号首次出现那段**的「译者注」里，并注明另一处所在段落。
- 拿不准原符号时保留原文写法并加「译者注」。

## 分段规则

1. **以自然段为单位**：一个空行（或明显的新段缩进）分隔的两段文字就是两段，出两张卡片。此规则对粘贴文本与提取文本同样适用。
2. **先合并再切段**：先修好段内硬换行，再切段。
3. **章节标题**译为 `## 2. 方法` 形式，作为分组标题，不单独出卡片。
4. **公式、图注、表注、脚注**并入所属段落的卡片，不单独成卡。
5. **列表**（项目符号或编号）整体视为一个自然段，出一张卡片。
6. **参考文献、作者与单位行、致谢、版权声明**默认整体跳过：不译、不出卡片、也不给原文摘录（用户只要卡片时同样跳过）。用户明确要求时才逐条处理，此时保留原文摘录。
7. **摘要**按自然段正常处理；**关键词**行单独出一张卡片（标题即关键词含义）。
8. **一段含两个主题**（如末段既讲结果又讲消融）时，仍按自然段出一张卡片，「核心知识」用两句分别覆盖；只有用户要求时才拆成两张。
9. **分批**：
   - 8 段及以下：一次输出完。
   - 9–30 段：每批最多 5 段，批间停下来问用户是否继续，每批开头重列一次术语表。
   - 31 段及以上：先给「章节地图」（每章一行：标题 + 段号范围 + 一句话内容 + 该章涉及的术语），再按用户点选的章节分批。
   - 用户要求「一次性写成文件」或「不要中途问我」时取消批间询问，一次写完整文件；此时术语表只出现一次，只有逐批交互输出时才在每批批首重贴。

## 译文规则

1. **忠实**：不增、不删、不概括、不评价。原文有歧义时译出歧义并加「译者注」。
2. **术语**：用学科通行译名，不用口语词或生造词；正文附注按第 3 步的「唯一规则」执行。
3. **原样保留**：公式与变量（`T = D`、`Re`）、单位（`kg·m⁻³`、`Hz`）、基因或蛋白或菌株名（`p53`、`E. coli`）、算法与软件与数据集专名（`Transformer`、`ImageNet`）、引用编号 `[12]`、图表编号 `Fig. 2`、代码与化学式。
4. **符号与格式**：源文本失真时按「符号与格式约定」还原；数值不变。
5. **数字与单位**：与原文一一对应，不改数值、不擅自换单位；需要换算时在括号内补充（`3 in ≈ 7.6 cm`）。
6. **统计量与因果**：hazard ratio、odds ratio、risk ratio、置信区间、P 值按原文表述翻译（风险比 / 比值比 / 相对危险度 / 置信区间）；不得添加原文没有的方向词（如把 `HR = 0.42` 写成「使风险降低 58%」），不得把 `HR < 1` 反推成某个概率「增加」；原文用 correlation、association 时不得改写成因果或「决定」。指标与其终点类型不匹配（如用 HR 汇报横断面概率）时照实翻译，并在「译者注」中说明。**本条同样适用于知识卡片。**
7. **人名、机构、期刊**：保留原文写法，附通行中文译名（`Froude` → 弗劳德）。
8. **句法**：拆开长定语从句；英文被动按中文习惯转为主动或「由……」「经……」；可压缩纯语法冗余（`It is noted that` 简化为「注意」），但不得删信息。
9. **一致性**：同一术语、同一符号全篇统一（含分批输出的跨批次一致）；中文里把 `it/they/this` 的指代还原成具体名词。
10. **语体**：学术书面语；用中文标点；不滥用「进行、性、化」，不出现「的的不休」与翻译腔。

## 卡片规则

每段一张卡片，四个字段必须齐全且紧扣该段：

- **标题**：不超过 15 字的名词短语，点出该段的知识主题，不是原文标题的直译。中英混排时中文按字、英文按词计，`d_k` 这类符号算 1 个词。
- **核心知识**：1–2 句，该段最值得记住的结论、机制或定义；纯背景段就概括其逻辑作用。
- **简明解释**：2–4 句，用同领域本科生能懂的话说明「为什么、怎么起作用」，把公式或术语的含义展开；不要照抄译文原句。允许补充教科书级的背景机制，但不得给出原文没有的结论或评价。
- **例子或自测问题**：二选一即可（推荐自测问题），两项都写也可以，但不能为空。必须能检验本段知识，禁止「请思考……」式的空问题。例子中若代入了原文未给出的参数（如阻力系数、幅值），必须写「（假设值）」，不得把假设值写成原文数据，也不得据此宣称「可用于校验」原文数据。

**卡片与译文受同样的忠实约束**：不得把原文的「相关」升级为「因果、决定」，不得补入原文没有的机制、强度或方向判断。卡片内容必须来自该段；跨段关联要标明（如「与第 3 段的 Re 呼应」）。

## 高频易错术语

跨学科最常译错的词，供第 2–3 步选词参考；表外术语按第 3 步流程判定。

| 原文 | 常见误译 | 学科内正确译法 |
|---|---|---|
| significant | 一律译「显著的」 | 统计学=显著的；一般语境=重要的、可观的 |
| control | 一律译「控制」 | 实验设计=对照（control group 对照组，control condition 对照条件） |
| cell line | 细胞线 | 细胞系 |
| expression | 一律译「表达式」 | 生物学=表达；数学与计算机=表达式 |
| robust | 鲁棒 | 统计学与机器学习=稳健（robustness 稳健性）；控制与工程=鲁棒亦可 |
| attention | 注意 | 深度学习=注意力机制 |
| embedding | 嵌入（当动词） | 名词=嵌入、嵌入向量 |
| ablation study | 消融研究 | 消融实验 |
| baseline | 基线 | 基线、基准方法（对照方法） |
| precision / accuracy / recall | 三词混用 | 精确率（查准率）/ 准确率 / 召回率（查全率） |
| bias | 一律译「偏见」 | 统计学与电子学=偏差、偏置；社会科学=偏见 |
| noise | 一律译「噪音」 | 信号与统计=噪声；声学两者皆可 |
| stress / strain | 应力应变不分 | stress=应力；strain=应变 |
| modulus | 模数 | 弹性模量（elastic modulus）；模数指齿轮模数 |
| cable-driven / tendon-driven | 缆驱动 | 绳驱动、线驱动（机器人传动语境） |
| torque / moment | 都译「力矩」 | torque=扭矩（转矩）；moment=力矩 |
| amplitude | 幅值、振幅混用 | 振动与波动=振幅；信号与统计=幅值 |
| compliance | 一律译「合规」 | 机器人=柔顺性；医学=顺应性；法律=合规 |
| damping / damper | 减震 | damping=阻尼；damper=阻尼器（减振器） |
| respectively | 分别地（前置） | 分别（放句末） |
| trial | 审判 | 医学=试验（clinical trial 临床试验） |
| sensitivity / specificity | 敏感性、特异性 | 诊断试验=灵敏度、特异度 |
| turbulence | 紊流 | 湍流（力学通行；紊流为旧称） |
| power | 一律译「功率」 | 物理学=功率；数学=幂；社会科学=权力 |
| dose | 用量 | 医学与药理=剂量 |

## 边界情况

- **输入已是中文**：说明无需英译汉，询问是否要做润色、术语校对或缩写成卡片。若用户选「卡片」，仍按第 2 步判定学科、按第 3 步给术语表。
- **非英语外语**（日、德、法）：可以译，但在「说明」行标注「术语基准较弱，必要时保留原文术语」。
- **中英混排**：只译英文部分，中文原样保留。
- **超长文档**：按「分段规则」第 9 条分批，不要一次吐完全文导致截断。
- **用户指定读者**（如「给大一学生看」）：只调整「简明解释」的深度，不降低译文的忠实度。
- **领域无法判定**：按通用学术译法处理，并在「说明」行标注「领域未明，术语按通用译法，可能需要人工复核」。

## 自检清单

交付前逐条确认；输入中不存在的元素（如无公式、无引用编号），在对应条目前标「不适用」，不要含糊放过。

1. 每段的「原文摘录 + 译文 + 四字段卡片」齐全，没有漏段或空字段（「只要卡片」变体下译文标「不适用」、摘录必留；「只要译文」变体下卡片与摘录标「不适用」）。
2. 卡片「例子或自测问题」能检验该段知识，不是空话；假设值已标注「（假设值）」。
3. 术语全篇（含分批的跨批次）一致；存疑处有「译名存疑」或「译者注」。
4. 括号附注：每段不超过 3 处（硬性），每个术语全篇只附注一次；候选超额时已按「候选超额时的优先级」取前 3 处。
5. 公式、变量、单位、引用编号、图表编号未被改写；失真符号已按「符号与格式约定」还原；同一符号多义处已消歧。
6. 数字与单位与原文一一对应，无错位、无擅自四舍五入；统计量未添加方向词，未把相关改成因果。
7. 没有增删信息、没有替作者下结论；卡片与译文一样忠实。
8. 中文标点、长句已拆、无翻译腔。
9. 段落数与原文自然段一致；段界若为推断已在「说明」行指出。
10. PDF 无文本层时已如实告知，未编造原文。
